# CONARE website (design concept)

A multi-page website concept for **CONARE** (Conservation of Nature through Rural Awakening), Achampet, Telangana, designed by Kreatif Atelier.

> This is a design concept, not CONARE's official website. Content is drawn from public sources such as conare.org; figures in the MIS report samples are illustrative.

Live preview: https://conare-site.vercel.app

## Run locally

```bash
npm install
npm run dev
```

Built with Vite, React, TypeScript, React Router and Tailwind CSS.
